# Waybar Config

This directory contains a my personal configuration for [Waybar](https://github.com/Alexays/Waybar), the status bar for Wayland.

## Files

- `config.jsonc`: main Waybar configuration
- `style.css`: styling for the bar

## Usage

Make sure Waybar is installed and configured to use this directory. For example, start it with:

```bash
waybar
```

If needed, point Waybar to this config directory in your Wayland compositor or launch script.

## Notes

This setup is intended for personal use and can be customized as needed.
